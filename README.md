# Plane Prototype

A small experimental project made with Godot.


This project is inspired by Flappy Bird and was created to practice player movement, obstacle generation, and collision detection.


## Features

- Tap-to-fly movement
- Procedurally spawned obstacles
- Collision detection
- Made with GDscript (Godot Enginee)


This is a learning project focused on gameplay mechanics and game development practice.
